# La quête du curry, les histoires des enfants

Page d'accueil qui réunit les livres écrits par les enfants pendant l'atelier « La quête du curry, une histoire dont tu es le héros », animé par le L.A.B dans les bibliothèques Méjanes d'Aix-en-Provence en octobre 2026. Chaque couverture mène au site du livre.

La page n'est pas référencée par les moteurs de recherche. Les couvertures sont dans `images/` (page 1 de chaque livret).

Réalisation : Laboratoire d'Aix-périmentation et de Bidouille.
